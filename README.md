# Data-ML Projects: Alpha Stage

A repository containing a collection of small projects from the early stages of my machine learning journey, focused on data preprocessing, basic modeling, and analysis.

## About This Repository

Welcome! This repository serves as my personal portfolio to document my growth in the field of data science and machine learning. Each project is organized into its own directory and includes the dataset (or instructions to acquire it), Jupyter notebooks with the analysis, and source code where applicable.

My goal is to apply and showcase skills in:
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Model Building and Training
- Hyperparameter Tuning and Optimization
- Model Evaluation and Interpretation
